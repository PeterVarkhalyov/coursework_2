# Курсовая работа 2

## Вступление

Учебное консольное приложение на Python, которое:

1. получает координаты и прямоугольные границы выбранных стран через Nominatim API;
2. передаёт эти границы в OpenSky API;
3. получает воздушные суда, находящиеся внутри найденных областей;
4. выводит результат в JSON;
5. позволяет сохранять, искать и удалять сведения о воздушных судах в JSON-файле.

Проект использует только стандартную библиотеку Python для выполнения HTTP-запросов. 
OpenSky API работает в анонимном режиме, без логина и пароля.

## Требования

- Python 3.12 или новее;
- Poetry 2.x — для установки dev-зависимостей и запуска проверок;
- доступ к интернету во время получения данных из API.

## Установка

Клонируйте проект и перейдите в его каталог:

```powershell
git clone <адрес-репозитория>
cd coursework_2
```

Установите зависимости:

```powershell
poetry install --no-root
```

Приложение не имеет обязательных сторонних runtime-зависимостей. Poetry устанавливает инструменты разработки:
`pytest`, `pytest-cov`, `flake8`, `mypy`, `isort` и `black`.

## Запуск

Передайте названия стран позиционными аргументами:

```powershell
poetry run python -m src Россия Германия
```

Если страны не переданы, программа запросит их интерактивно:


Программа возвращает JSON следующей структуры:

```json
{
  "attribution": [
    "Geocoding © OpenStreetMap contributors, ODbL 1.0",
    "Aircraft data © The OpenSky Network"
  ],
  "result": true,
  "msg": {
    "code": 0,
    "error": null
  },
  "count": 1,
  "time": 1766142246,
  "countries": [
    {
      "country": {
        "name": "Россия",
        "country_code": "RU",
        "latitude": 64.6863136,
        "longitude": 97.7453061,
        "bounding_box": {
          "south": 41.1850968,
          "north": 82.0586232,
          "west": -180.0,
          "east": 180.0
        }
      },
      "data": {
        "count": 1,
        "time": 1766142240,
        "aircraft": [
          {
            "icao24": "abc123",
            "callsign": "TEST1",
            "origin_country": "Russian Federation",
            "time_position": 1793450000,
            "last_contact": 1793450005,
            "longitude": 37.6176,
            "latitude": 55.7558,
            "baro_altitude": 10000.0,
            "on_ground": false,
            "velocity": 230.0,
            "true_track": 90.0,
            "vertical_rate": 1.5,
            "sensors": [1, 2],
            "geo_altitude": 10100.0,
            "squawk": "7000",
            "spi": false,
            "position_source": 0
          }
        ]
      }
    }
  ]
}
```

Значения некоторых полей могут быть `null`, если OpenSky не располагает соответствующими данными.
Верхний `time` содержит время формирования общего результата, а `countries[].data.time` — время сервера OpenSky
из ответа `states/all` для соответствующей страны.

При ошибке возвращается ответ следующего вида:

```json
{
  "attribution": [
    "Geocoding © OpenStreetMap contributors, ODbL 1.0",
    "Aircraft data © The OpenSky Network"
  ],
  "result": false,
  "msg": {
    "code": 1000,
    "error": "Сообщение об ошибке"
  },
  "count": 0,
  "time": 1766142246,
  "countries": []
}
```

## Архитектура

Поток данных:

```text
Названия стран
      ↓
NominatimAPI
      ↓
CountryCoordinates + BoundingBox
      ↓
OpenSkyAPI
      ↓
время сервера + list[AircraftState]
      ↓
AirspaceCollector
      ↓
dict с результатом, временем и данными стран

AircraftState
      ↓
AbstractAircraftStorage
      ↓
JSONAircraftStorage → JSON-файл
```

Основные классы:

- `AbstractAPIClient` — абстрактный родительский класс и общий HTTP-метод;
- `NominatimAPI` — поиск страны, получение координат и границ;
- `OpenSkyAPI` — получение и разбор state vectors воздушных судов;
- `AirspaceCollector` — объединение данных Nominatim и OpenSky;
- `BoundingBox` — прямоугольные географические границы;
- `CountryCoordinates` — сведения о стране;
- `AircraftState` — состояние одного воздушного судна;
- `CountryAirspace` — итоговые данные по одной стране;
- `AbstractAircraftStorage` — общий интерфейс файлового или удалённого хранилища;
- `JSONAircraftStorage` — добавление, поиск и удаление воздушных судов в JSON-файле.

### Модуль `__init__.py`

Модуль отмечает каталог `src` как пакет Python и определяет его публичный интерфейс. Он импортирует основные
классы из остальных модулей, благодаря чему их можно получать непосредственно из пакета:

```python
from src import AirspaceCollector, NominatimAPI, OpenSkyAPI
```

Список `__all__` содержит имена, которые считаются публичной частью проекта:

- `APIError` и `AbstractAPIClient`;
- клиенты `NominatimAPI` и `OpenSkyAPI`;
- модели `BoundingBox`, `CountryCoordinates`, `AircraftState` и `CountryAirspace`;
- сервис `AirspaceCollector`;
- интерфейс `AbstractAircraftStorage`, JSON-коннектор `JSONAircraftStorage` и `StorageError`;
- заглушки `CSVAircraftStorage`, `TXTAircraftStorage`, `XLSXAircraftStorage` и `SQLAircraftStorage`.


### Модуль `models.py`

Модуль содержит dataclass-модели, описывающие данные приложения. Он не обращается к внешним API и не зависит от
формата пользовательского ввода.

Модели позволяют передавать между слоями программы типизированные объекты вместо необработанных JSON-словарей и
массивов.

#### Class `BoundingBox`

Хранит южную, северную, западную и восточную границы. 

##### Метод `__post_init__()` 

Проверяет диапазоны  широты и долготы.

##### Метод `contains()` 

Определяет попадание точки в прямоугольник.

##### Метод `to_query_params()` 

Формирует  параметры `lamin`, `lamax`, `lomin` и `lomax` для OpenSky.

#### Class `CountryCoordinates` 

Хранит название страны, код ISO, координаты центральной точки и объект `BoundingBox`.

#### Class `AircraftState` 

Представляет `state vector` одного воздушного судна. 
Модель содержит:
- идентификатор ICAO24,
- позывной, 
- страну регистрации, 
- координаты, 
- высоту, 
- скорость, 
- курс, 
- данные сенсоров 
- состояние транспондера.

Поля с типом `... | None` могут отсутствовать в ответе OpenSky.

При создании объекта выполняется валидация данных:

- `icao24` должен состоять из шести шестнадцатеричных символов;
- `origin_country` должен быть непустой строкой;
- `callsign` и `squawk` очищаются от пробелов и могут принимать значение `None`;
- координаты должны находиться в диапазонах от `-90` до `90` и от `-180` до `180`;
- скорость не может быть отрицательной;
- курс должен находиться в диапазоне от `0` до `360` градусов;
- временные метки и источник позиции должны быть целыми неотрицательными числами или `None`;
- `on_ground` и `spi` должны иметь тип `bool`;
- `sensors` должен быть списком целых чисел или `None`.

Свойство `altitude` возвращает `geo_altitude`. Если геометрическая высота неизвестна, используется
`baro_altitude`.

Методы сравнения:

| Метод | Назначение | Результат |
|---|---|---|
| `compare_speed(other)` | Сравнение по `velocity` | `-1`, `0` или `1` |
| `compare_altitude(other)` | Сравнение по свойству `altitude` | `-1`, `0` или `1` |
| `is_faster_than(other)` | Проверка, быстрее ли текущий самолёт | `bool` |
| `is_higher_than(other)` | Проверка, выше ли текущий самолёт | `bool` |

Значение `-1` означает, что текущий самолёт медленнее или ниже, `0` — значения равны, `1` — текущий самолёт
быстрее или выше. Сравнивать можно только объекты `AircraftState`. Если отсутствуют скорость или оба значения
высоты, метод сравнения выбрасывает `ValueError`.

#### Class `CountryAirspace` 

Объединяет сведения о стране и список найденных в её прямоугольных границах воздушных судов.

### Модуль `api.py`

Модуль отвечает за сетевое взаимодействие с Nominatim и OpenSky, проверку ответов и преобразование JSON в модели
из `models.py`. HTTP-запросы выполняются средствами стандартной библиотеки Python.

#### Class `APIError` 

Единый тип исключения для ошибок соединения, HTTP-ответов и некорректных данных.


#### Class `AbstractAPIClient` 

Абстрактный родительский класс. Он хранит базовый URL и тайм-аут, требует реализацию метода `connect()` и предоставляет 
общий метод `_request_json()` для GET-запросов и разбора JSON.

#### Class `NominatimAPI` 

Получает центральные координаты, ISO-код и прямоугольные границы страны. 
Клиент передаёт обязательный `User-Agent`, выдерживает интервал между запросами не менее одной секунды и хранит найденные страны
  во внутреннем кэше на время работы программы.
  
#### Class `OpenSkyAPI` 

Запрашивает endpoint `states/all` по границам `BoundingBox`, преобразует массивы OpenSky в объекты `AircraftState`,
сохраняет время ответа сервера, исключает некорректные записи и при необходимости удаляет объекты, находящиеся
на земле.

Вспомогательные методы `_to_float()`, `_to_int()` и `_to_int_list()` безопасно преобразуют необязательные значения
из ответа OpenSky. Если значение отсутствует или имеет неподходящий формат, они возвращают `None`.

Сетевые исключения `HTTPError`, `URLError`, `TimeoutError` и ошибки разбора JSON преобразуются в `APIError`, чтобы
вызывающий код мог обрабатывать все проблемы API единообразно.

### Модуль `service.py`

Модуль содержит сервисный слой `AirspaceCollector`, который связывает клиентов Nominatim и OpenSky. Клиенты
передаются через конструктор и сохраняются в атрибутах `nominatim` и `opensky`.

Метод `collect()` выполняет следующую последовательность:

1. удаляет пробелы из названий стран и исключает пустые значения;
2. запрашивает через `NominatimAPI` координаты и `BoundingBox` каждой страны;
3. передаёт границы в `OpenSkyAPI`;
4. получает время сервера OpenSky и список объектов `AircraftState`;
5. преобразует модели страны и самолётов в JSON-совместимые словари;
6. возвращает общий словарь с результатом, кодом, временем и данными стран.

Параметр `airborne_only` передаётся клиенту OpenSky и позволяет исключить наземные объекты. Если после очистки не
осталось ни одного названия страны или один из API-клиентов вернул ошибку, метод возвращает ответ с
`result: false`, кодом `1000` и текстом ошибки.

### Модуль `storage.py`

Модуль содержит коннекторы для хранения объектов `AircraftState`. Общий абстрактный интерфейс позволяет заменить
JSON-файл другим форматом, базой данных или удалённым хранилищем, не меняя код, который использует хранилище.

#### Class `StorageError`

Единое исключение для ошибок чтения, проверки и записи хранилища. Например, оно возникает, если JSON повреждён,
имеет неправильную структуру или содержит запись, из которой нельзя создать корректный `AircraftState`.

#### Class `AbstractAircraftStorage`

Абстрактный базовый класс требует от каждого коннектора реализации трёх методов:

| Метод | Назначение | Результат |
|---|---|---|
| `add_aircraft(aircraft)` | Добавляет один объект `AircraftState` | `None` |
| `get_aircraft(criteria=None)` | Возвращает записи, совпавшие со всеми критериями | `list[AircraftState]` |
| `delete_aircraft(criteria)` | Удаляет записи, совпавшие со всеми критериями | Количество удалённых записей |

Сам `AbstractAircraftStorage` нельзя создать напрямую. Он определяет контракт, который должен соблюдаться всеми
конкретными хранилищами.

#### Class `JSONAircraftStorage`

Рабочая реализация файлового хранилища. По умолчанию данные записываются в `data/aircraft.json`, но другой путь
можно передать при создании объекта. Файл содержит JSON-массив, где каждый элемент соответствует одному
`AircraftState`.

Основные правила работы:

- отсутствующий файл считается пустым хранилищем и создаётся при первом добавлении;
- каталог для файла создаётся автоматически;
- данные записываются в UTF-8 с сохранением кириллицы;
- без критериев `get_aircraft()` возвращает все записи;
- несколько критериев объединяются по правилу «И»: запись должна соответствовать каждому значению;
- неизвестные названия атрибутов в критериях вызывают `ValueError`;
- удаление без критериев запрещено, чтобы исключить случайную очистку всего файла;
- после чтения каждая запись проходит валидацию конструктора `AircraftState`.

Пример использования:

```python
from src import JSONAircraftStorage

storage = JSONAircraftStorage("data/aircraft.json")
storage.add_aircraft(aircraft)

fast_aircraft = storage.get_aircraft({"origin_country": "Russian Federation", "on_ground": False})
deleted_count = storage.delete_aircraft({"icao24": "abc123"})
```

Сравнение значений критериев выполняется на точное равенство. Например, критерий `{"on_ground": False}` вернёт
только воздушные суда, для которых атрибут `on_ground` равен `False`.

#### Заглушки других хранилищ

Классы `CSVAircraftStorage`, `TXTAircraftStorage`, `XLSXAircraftStorage` и `SQLAircraftStorage` объявлены как основы
для будущих коннекторов. Пока они не реализуют абстрактные методы, поэтому создать их экземпляры нельзя. Для
поддержки нового формата необходимо реализовать в соответствующем классе методы `add_aircraft()`,
`get_aircraft()` и `delete_aircraft()`.

## Ограничения

- OpenSky фильтрует данные по прямоугольнику `BoundingBox`, а не по точной государственной границе. Поэтому в
  результат могут попасть воздушные суда над соседними территориями или морями.
- `origin_country` означает страну, определённую по ICAO24-адресу транспондера, а не страну текущего положения.
- Анонимные запросы OpenSky имеют ограничения по квоте и частоте.
- Наличие воздушного судна в ответе зависит от покрытия OpenSky и доступности актуальных координат.
- Кэш Nominatim хранится только в памяти и очищается после завершения программы.
- Клиент выдерживает интервал не менее одной секунды между запросами к публичному Nominatim.
